Copper Canyon Courier — a bush-pilot mail run at dusk. Fly the prop plane through 14 glowing rings over the mesa, slalom the canyon walls, mind fuel and hull damage, and land soft on dirt runway 27. Three legs with different goals, a lit instrument cluster (attitude, altimeter, airspeed), and a fixed-step simulation with deterministic seeded rings (`?seed=N`, `?shot=start|play|land|end` stages screenshot scenes).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — `← →` bank and turn · `↑ ↓` pitch · `W / S` throttle · `P` pause · `Enter` take off / fly again.
